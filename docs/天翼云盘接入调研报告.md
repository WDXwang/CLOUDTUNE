# 天翼云盘（个人云）第三方接入能力技术调研报告

> 调研目标：为一款安卓音乐播放器 App 评估"列出天翼云盘音乐文件 + 获取可 HTTP 流式播放（支持 Range 拖动）直链"的技术路线。
> 调研时间：2026-10-27 ｜ 调研对象：cloud.189.cn / api.cloud.189.cn / open.e.189.cn / id.189.cn
> 说明：本报告区分**官方开放 API**与**社区逆向出的 Web/App 内部 API**两条线，所有关键结论均附来源 URL。

---

## 0. 结论速览（TL;DR）

| 问题 | 结论 |
|---|---|
| 个人开发者能否用官方 OAuth 接天翼云盘文件 API？ | 官方**有**文件级 REST API（listFiles/getFileDownloadUrl 等），但开放平台接入主体明确要求**企业开发者**（APPID/AppSecret 走审批），普通个人开发者基本拿不到云盘文件能力权限。 |
| 能否用非官方 Web/App API 列文件 + 拿播放直链？ | **可以**，社区已有成熟实现（AList 189pc 驱动、cloudpan189-go、油猴脚本等）。登录走 open.e.189.cn 账密 RSA 加密登录换 Cookie/AccessToken，下载直链由 `getFileDownloadUrl` 返回。 |
| 直链能否流式拖动播放？ | 能。下载直链是 CDN 地址，支持 HTTP Range（206 分段），社区库明确按 Offset/End 分段下载；直链有有效期（小时级，过期需重新换取），通常经 302 跳转。 |
| 天翼云盘原生支持 WebDAV 吗？ | **不支持**。需自建 AList 做 WebDAV 中转（`/dav/`）。 |
| 推荐 App 路线 | **推荐 B 路线为主、A 路线为进阶**：普通用户接自建/可配的 AList（WebDAV 标准客户端，封号风险隔离在服务端）；重度/自托管用户可选 A 路线直连非官方 API。下文详述。 |

## 1. 官方开放平台 / OAuth 接入能力

### 1.1 官方确实存在面向第三方的云盘开放能力
天翼云盘开放平台页面明确："天翼云盘开放平台……面向**个人和组织开发者**，提供能力接入、开发升级、发布推广的一站式服务平台"，并列出"商务机构开发者 / 个人独立开发者"两类入口。
- 来源：https://m.cloud.189.cn/zhuanti/2023/cloud-open-platform/index.html
- 能力开放主页：https://cloud.189.cn/open/web_main/index_open.html

天翼数字生活账号开放平台（id.189.cn）提供了**完整的云盘文件 REST API 定义**，与本需求直接相关的端点如下（均在 `api.cloud.189.cn`）：

| 能力 | 端点 |
|---|---|
| 获取用户基本信息 | `GET http://api.cloud.189.cn/getUserInfo.action` |
| 获取用户扩展信息 | `GET http://api.cloud.189.cn/getUserInfoExt.action` |
| **获取文件列表** | `POST http://api.cloud.189.cn/listFiles.action` |
| 获取文件夹信息 | `http://api.cloud.189.cn/getFolderInfo.action` |
| 获取文件信息 | `http://api.cloud.189.cn/getFileInfo.action` |
| 文件搜索 | `POST http://api.cloud.189.cn/searchFiles.action` |
| **获取文件下载地址** | `http://api.cloud.189.cn/getFileDownloadUrl.action` |
| 批量获取下载地址 | `http://api.cloud.189.cn/batchGetFileDownloadUrl.action` |
| 上传（一次性/断点续传） | `upload.cloud.189.cn/uploadFile.action`、`createUploadFile.action` 等 |

- 来源（接口总表 + 签名机制）：https://id.189.cn/html/api_detail_121.html
- 接入天翼云盘能力清单（用户信息/文件查询/管理/下载/批处理/上传/相册/高级权限）：http://id.189.cn/api?initialSrc=/html/api_detail_607.html
- 搜索接口参数样例（folderId/filename/recursive/fileType/**mediaType=2 即音乐**/mediaAttr/pageNum/pageSize）：https://id.189.cn/html/api_detail_141.html

**鉴权与签名（官方 OAuth2 方式）：**
- 请求头必须带 `AccessToken`（OAuth2 Token）、`Date`、`Host`，以及 `Signature`。
- 签名公式：
  `Signature = hmac_sha1("AccessToken=<值>&Operate=<GET/POST/PUT/DELETE>&RequestURI=<路径>&Date=<值>", AppSecret)`
- 即标准 OAuth2 AccessToken + HMAC-SHA1 签名，AppSecret 由开发者应用下发。
- 来源：https://id.189.cn/html/api_detail_121.html

OAuth 授权登录流程（open.e.189.cn）：合作方 iframe 嵌入登录框 → 用户认证后回调带 `code` → 服务端用 `code` 换 `accessToken` → 再调云盘 API。
- 登录框接口：`GET https://open.e.189.cn/api/logbox/oauth2/separate/unifyAccountLogin.do`
- 公共参数：`appId`、`clientType=10010`、`format=redirect`、`version=v2.0`、`paras`（用 AppSecret 做 **XXTea** 加密）、`sign=HMAC-SHA1(appId+clientType+format+version+paras, AppSecret)`
- 来源：https://id.189.cn/html/api_detail_469.html

### 1.2 个人开发者能否注册？——结论：基本走不通（需企业资质审批）
- 官方《WEB登录框开发指南》"接入准备"明确写道：**"接入方在天翼账号开放平台申请企业开发者、应用 APPID、及免密登录权限"**。
  来源：https://id.189.cn/html/api_detail_469.html
- 虽然开放平台宣传页同时列出"个人独立开发者"，但那是面向**小程序生态/渠道分发**的入口；真正能拿到云盘文件读/下载 OpenAPI 的，是经过中国电信商务审核的**企业/机构合作方**模式，需要 APPID + AppSecret 审批，不是注册即开通。
  来源：https://m.cloud.189.cn/zhuanti/2023/cloud-open-platform/index.html

> **对 App 的含义**：作为一个个人/小众安卓音乐播放器，走"官方 OAuth 拿 AccessToken 直调 listFiles/getFileDownloadUrl"在现实中拿不到资质。官方 API 文档虽在，但权限审批门槛对独立开发者不友好。因此工程上真正被广泛使用的是下一节的**非官方 Web/App 内部 API**。

## 2. 非官方 API（Web 端 / App 端内部接口）真实情况

这是社区（AList、cloudpan189-go、小白羊、各类签到脚本/直链脚本）实际在用的路径。域名主要为 `open.e.189.cn`（登录）、`api.cloud.189.cn`（业务）、`cloud.189.cn`（Web portal）、`h5.cloud.189.cn`（家庭云 H5）。

### 2.1 登录认证流程（账密 + RSA 加密）
以一个仍在维护的签到脚本（2026-05 仍修复登录接口）为实证，完整链路如下：

1. `GET https://m.cloud.189.cn/udb/udb_login.jsp?pageId=1&pageKey=default&clientType=wap&redirectURL=...` 拿到带 `autoLogin` 的动态登录页。
2. 跟随重定向，从最终 URL 解析查询参数，`POST https://open.e.189.cn/api/logbox/oauth2/wap/appConf.do` 取登录配置，返回 `lt`、`returnUrl`、`paramId`、`accountType`。
3. 打开 login.html 页面，正则取出 `<input id="j_rsaKey" value="...">` 的 **RSA 公钥**。
4. 用该公钥分别 RSA 加密用户名与密码，拼成 `{RSA}<base64(密文)>` 形式（脚本里还把 base64 输出再转成 hex 串）。
5. `POST https://open.e.189.cn/api/logbox/oauth2/loginSubmit.do`，字段：
   - `appKey=cloud`、`accountType`、`userName={RSA}...`、`password={RSA}...`、`validateCode`、`captchaToken`、`returnUrl`、`mailSuffix=@189.cn`、`paramId`
6. 返回 `toUrl`，再 `GET toUrl` 完成会话种 Cookie；之后即可带着会话 Cookie 访问 `api.cloud.189.cn`。
- 实证源码：https://github.com/vistal8/tianyiyun （raw: http://raw.githubusercontent.com/vistal8/tianyiyun/refs/heads/main/tianyiyun.py ）
- HAR 抓包佐证登录端点：`e.189.cn/api/logbox/oauth2/loginSubmit.do`（http://raw.githubusercontent.com/AyeSt0/qd-templates/master/189天翼云(账号密码版).har ）

**关键风险点（脚本作者原话）**："有图形验证码就是风控了，更换 IP 后再试；自己去网页端登录输入验证码，还不行就静默几天。" —— 说明账密直登路径有**滑块/图形验证码风控**。
- 来源：同上 tianyiyun.py 注释。

AList 官方文档也确认："Web 端登录已更换为**滑动验证码**，不再支持 OCR 与手动输入，若需要验证码请使用**添加 Cookie 登录**或使用'天翼云盘客户端'驱动。"
- 来源：https://alist.nn.ci/zh/guide/drivers/189.html

### 2.2 登录后持有的会话/令牌字段
cloudpan189-api（Go 版成熟客户端库）的 `AppLoginToken` 结构，列出了登录成功后服务端下发的全部关键令牌：

```
SessionKey, SessionSecret           // 个人云会话
FamilySessionKey, FamilySessionSecret // 家庭云会话（独立）
AccessToken, RefreshToken
SskAccessToken, SskAccessTokenExpiresIn
RsaPublicKey
```
- 另有 `RefreshCookieToken(sessionKey)` 用于刷新 Cookie token。
- 来源：https://pkg.go.dev/github.com/tickstep/cloudpan189-api/cloudpan

即：**个人云与家庭云是两套独立 session**（sessionKey vs familySessionKey），这与 AList 把"个人云(189pc)"和"家庭云(189CloudPc/客户端驱动)"分成两个驱动完全吻合。

### 2.3 文件列表 / 文件夹导航接口

**个人云（App/Web 内部 API）：**
- `AppFileList(param)` / `AppGetAllFileList(param)`：获取某 folderId 下文件列表，分页。
- `FileInfoByPath(path)` / `FileInfoById(fileId)`：按路径或 ID 取文件信息。
- 根目录 folderId 约定：Web 端 URL 末尾那串，如 `https://cloud.189.cn/web/main/file/folder/-11` → `-11`（根目录固定为 `-11`）。
- 来源（函数清单）：https://pkg.go.dev/github.com/tickstep/cloudpan189-api/cloudpan
- 来源（根目录 ID 取法）：https://alist.nn.ci/zh/guide/drivers/189.html

**家庭云：**
- `AppFamilyGetFamilyList()`：列出我加入的家庭，返回 `familyId`、`userRole`、`createTime` 等。
- 家庭云文件列表/导航走 `familySessionKey` + `familyId` 这一套独立会话；AList 要求用手机仿真模式打开 `https://h5.cloud.189.cn/main.html#/family`，从 F12 网络请求里手工抓 `family_id`（根 folder id）等参数。
- 家庭云与个人云空间相互独立、互不占空间。
- 来源：https://alist.nn.ci/zh/guide/drivers/189.html ；https://home.cloud.189.cn/web/helpCenter.html

### 2.4 获取下载 / 播放直链接口
社区直链脚本（LinkSwift.user.js）实证的个人云取链过程：

- 先 `GET https://api.cloud.189.cn/open/oauth2/ssoH5.action`，从最终 URL 正则取 `accessToken=...`。
- 再 `GET https://api.cloud.189.cn/open/file/getFileDownloadUrl.action?fileId=<fileId>`，请求头带：
  - `accesstoken: <token>`
  - `timestamp: <毫秒>`
  - `signature: md5("AccessToken="+token+"&Timestamp="+time+"&fileId="+fileId)`（分享文件时再加 `&dt=1&shareId=...`）
- 成功响应 `res_code===0`，返回体里 **`fileDownloadUrl` 即为可下载的 CDN 直链**；`errorCode==='InvalidSessionKey'` 表示会话失效需重新登录。
- 来源（脚本中的 tcloud 段）：https://scriptcat.org/scripts/code/1604/LinkSwift.user.js

**家庭云取链**：`AppFamilyGetFileDownloadUrl(familyId, fileId)` 单独签名（用 familySessionKey 体系），返回同样是下载 URL。
- 来源：https://pkg.go.dev/github.com/tickstep/cloudpan189-api/cloudpan

**直链行为特性（是否支持流式 / Range / 有效期 / 302）：**
- **支持 HTTP Range（可拖动进度）**：cloudpan189-api 明确暴露 `AppFileDownloadRange{Offset int64; End int64}`（起始含/结束含），并有 `AppDownloadFileData(downloadFileUrl, fileRange, ...)` 分段下载方法——即底层直链按字节区间拉取，等价于 HTTP Range/206，可直接喂给 ExoPlayer/OkHttp 的 `setRange` 做拖动。家庭云同理有 `AppFamilyDownloadFileData(..., fileRange, ...)`。
  - 来源：https://pkg.go.dev/github.com/tickstep/cloudpan189-api/cloudpan
- **302 跳转**：AList 下载方式提供"默认 / 备选 / **302** / 本机代理 / 代理URL"多档，说明天翼云盘下载地址通常以 302 重定向到 CDN 分片地址；播放器需要允许跟随 302（ExoPlayer/媒体播放器默认跟随）。
  - 来源：https://alist.nn.ci/zh/guide/drivers/189.html
- **有效期**：天翼系对象/临时 URL 普遍有时效（天翼云 OSS 临时 URL 默认 24h、企业文档预签名 3 天等可作旁证）；个人云 `fileDownloadUrl` 属短时签名链接（小时级），过期需用同一 fileId 重新调 `getFileDownloadUrl` 换新链。App 应"播放前现取现用、缓存短 TTL"，不要长期保存直链。
  - 旁证（临时 URL 有效期机制）：https://www.ctyun.cn/document/10306929/10136419 ；https://www.ctyun.cn/document/11032279/11094184
- **结论**：拿到 `fileDownloadUrl` 后，它就是一个带签名的 HTTP(S) CDN 地址，支持 Range，可直接作为媒体源流式播放，**无需先下载整文件**。✅

### 2.5 签名 / 加密参数清单（非官方）
| 名称 | 用途 | 出处 |
|---|---|---|
| `j_rsaKey`（RSA 公钥） | 登录页动态下发，加密用户名/密码 | tianyiyun.py |
| `{RSA}...` | 加密后的账密提交格式 | tianyiyun.py |
| `lt` / `paramId` / `returnUrl` / `accountType` | appConf.do 下发的登录上下文 | tianyiyun.py |
| `sessionKey` / `sessionSecret` | 个人云会话凭证 | cloudpan189-api |
| `familySessionKey` / `familySessionSecret` | 家庭云会话凭证 | cloudpan189-api |
| `accessToken` / `refreshToken` / `sskAccessToken` | OAuth/App 令牌 | cloudpan189-api |
| Cookie（`COOKIE_SESSION` / `SSON` 等） | Web 端登录态，AList 现在推荐直接填 Cookie 免过滑块 | alist 文档 |

## 3. 天翼云盘是否原生支持 WebDAV？
**不支持（个人版/家庭云均无官方 WebDAV 服务）。**
- 天翼云盘官方帮助中心只提供 PC/手机/TV 客户端与 Web，未提供任何 WebDAV/挂载说明。
- 网络上能搜到的"天翼云 WebDAV 服务"全都是**第三方自建**（如"基于 FastAPI + 天翼云盘"自写的 `/dav/` 服务），并非中国电信官方能力。
  - 旁证：http://121.37.130.94:35000/ （一个自建的天翼云 WebDAV 演示站）
- 官方对象存储产品（CTYun OSS）另支持 S3/分片，但那是企业对象存储，与个人云盘不是同一套、也不面向个人盘用户开放。
  - 来源：https://www.ctyun.cn/document/10306929/10307450

> **结论**：个人云盘原生无 WebDAV。要拿 WebDAV，必须自建 AList（或类似网关）做协议转换。

## 4. 自建 AList 对接天翼云盘方案

### 4.1 AList 对天翼云盘的支持
AList 官方文档确认有两个相关驱动：
- **"电信天翼云盘"（189pc，个人云）**：填手机号、密码、根文件夹 ID（默认 `-11`）。Web 端登录已上滑块验证码，**推荐直接粘贴浏览器 Cookie 登录**（Cookie 有效期未知，过期需重抓）。
- **"天翼云盘客户端"（189CloudPc，含家庭云）**：可在"个人云 / 家庭云"间切换；家庭云参数（family_id 等）需从 `h5.cloud.189.cn/main.html#/family` 的 F12 请求里抓。
- 官方建议：**首选"天翼云盘客户端"驱动**；下载方式默认走"302"。
- 来源：https://alist.nn.ci/zh/guide/drivers/189.html ；https://alist-doc.nn.ci/docs/driver/189/

AList WebDAV 能力矩阵中，**天翼云盘：列表✅ 下载✅ 上传✅ 重命名/移动/复制✅**。
- 来源：https://alist-doc.nn.ci/docs/webdav/

### 4.2 AList WebDAV 端点形态
| 参数 | 值 |
|---|---|
| 链接 | `http[s]://域名:端口/dav/` |
| 主机 | `域名:端口` |
| 路径 | `/dav` |
| 协议 | http/https（强烈建议 https） |
| 端口 | 同 Web 管理端口（默认 5244） |
| 账号 | AList 后台用户 |
| 密码 | AList 后台密码 |
| 权限要求 | v3.42.0+ 需在 用户→权限 单独开启 **Webdav Read**（只读播放足够）；要写才开 Webdav Manage |

- 来源：https://alist-doc.nn.ci/docs/webdav/ ；https://alistgo.com/guide/webdav
- 已有大量第三方播放器通过 WebDAV 挂载 AList 的先例：PC 用 PotPlayer / RaiDrive，安卓/TV/iOS 用 nPlayer、Kodi 等。
  - 来源：https://alist-doc.nn.ci/docs/webdav/

### 4.3 用它做"播放中转"的工作方式
```
安卓音乐播放器 ──WebDAV(PROPFIND 列目录 / GET 取文件流)──> 自建 AList(/dav/)
                                                              │ 内部用 Cookie/AccessToken
                                                              ▼
                                                    天翼云盘 api.cloud.189.cn
                                                    (列文件 + getFileDownloadUrl 拿 CDN 直链)
```
- 播放器只需实现标准 WebDAV 客户端：`PROPFIND` 列目录拿到歌曲列表（名称/大小/修改时间），`GET /dav/路径/歌名.mp3` 拉流；AList 在服务端把它翻译成天翼云盘的列文件 + 取 CDN 直链 + 302/反代。
- 直链的有效期、签名、Cookie 续期**全部被 AList 屏蔽**，App 侧面对的是稳定的 `/dav/` URL。

### 4.4 部署成本与局限
- **成本**：需要一台常驻服务器（家里 NAS / 一台 VPS / 路由器 docker 均可），AList 单二进制或 docker 即可；带宽是主要成本——若用"本机代理/反代"模式，所有歌曲流都要过你的服务器带宽；若用"302 直跳"模式，流量直连天翼 CDN，服务器只做信令。
- **局限**：
  1. 用户要自己部署 AList 并填天翼云盘 Cookie——**对普通用户门槛偏高**；
  2. Cookie 会过期/被风控，需要用户重新抓，AList 端要有人维护；
  3. 302 模式下 App 要能正确跟随重定向；反代模式耗带宽；
  4. 仍属"非官方对接"，封号/风控风险由 AList 这台服务承担，不直接打到用户手机。
- 旁证（同类直链解析服务 p189 专享版）：https://git-hub.com/qaiu/netdisk-fast-download

## 5. 两条路线对比（A：App 直连非官方 API vs B：App 当 WebDAV 客户端连自建 AList）

| 维度 | A) App 内直连天翼云盘 Web 非官方 API | B) App 作 WebDAV 客户端 → 自建 AList → 天翼云盘 |
|---|---|---|
| **稳定性** | 差-中。天翼一改登录（已多次上滑块验证码）、一改签名/`j_rsaKey`，App 就要跟版发版；登录态/Cookie 易失效。 | **较好**。协议层是标准 WebDAV，只要 AList 在更新适配天翼，App 不用动；天翼 API 变动由 AList 社区吸收。 |
| **账号风险（封号/验证码/风控）** | **高，且直接落在用户本人手机/IP**。账密直登 + 固定 User-Agent + 高频取链，极易触发滑块/图形验证码甚至限登；每个用户手机都在跑逆向登录。 | **低且隔离**。登录/Cookie/取链集中在 AList 服务端，可控制频率、统一换 Cookie；普通用户手机只连自己的 AList，不直接碰天翼风控面。代价是 AList 那台服务的账号要承担风险。 |
| **合规性** | 最差。App 内置逆向账密 RSA 登录 + 未授权签名，违反天翼云盘服务协议（中国电信有权对异常账号限制功能/冻结）。 | 略好（仍灰）。App 侧只是标准 WebDAV 客户端，合规问题集中在 AList 服务端；但"用非官方驱动挂个人盘"本质仍踩服务协议。 |
| **实现难度** | 高。要在安卓端实现 RSA 加密登录、处理滑块/验证码、维护 sessionKey/familySessionKey、md5 签名取链、直链过期重取。 | **低**。WebDAV 客户端在安卓生态很成熟（可直接用现成 WebDAV 库）；列目录=PROPFIND，播放=GET 流，天然支持 Range。 |
| **用户体验** | 理论上最顺（少一跳、直连 CDN），但登录验证码/掉线会频繁打断播放。 | 列目录体验标准一致；302 模式播放直连 CDN 不慢；但要求用户自备/自填 AList 地址，门槛高。 |

**风险隔离的关键点**：A 路线把逆向登录和风控暴露在**每个用户的设备**上；B 路线把它收拢到**一个可控的服务端**，这是 B 在账号安全上的最大优势。

## 6. 推荐的 App 架构路线

**推荐：以 B 路线为主，预留 A 路线给自托管玩家。**

```
┌─────────────────────────────────────────────┐
│  安卓音乐播放器                                │
│  ┌───────────────────────────────────────┐ │
│  │ 统一云端文件抽象层 (CloudSource 接口)     │ │
│  │  - listMusic(folder) → List<Song>      │ │
│  │  - getStreamUrl(song) → 可播直链(Range) │ │
│  └───────────────┬───────────────────────┘ │
│                  │ 两个实现                    │
│   ┌──────────────┴──────────────┐          │
│   ▼                              ▼          │
│ WebDAVSource(B, 默认)        Direct189Source(A, 可选)│
│ 连用户自建 AList /dav/       内置逆向登录+取链      │
│ PROPFIND/GET                 open.e.189.cn + api.cloud.189.cn │
└─────────────────────────────────────────────┘
```

**理由与落地建议：**
1. **默认交付 B（WebDAV + AList）**：App 只实现标准 WebDAV 客户端（填服务器地址/账号/密码），列音乐、流式播放全部标准化；Range 拖动由 HTTP GET 原生支持。把"对接天翼云盘"这件最易变、最易触发风控的事，交给持续维护的 AList。
2. **播放直链处理**：WebDAV `GET /dav/.../xx.mp3` 本身就是流式地址，ExoPlayer/Media3 直接做数据源即可；若 AList 配 302 模式，确认播放器允许跟随跨域 302。
3. **A 路线作为"高级/实验"开关**：给愿意折腾的用户内置直连（登录走 Cookie 粘贴，**不要让用户在 App 里输明文密码**以降低风控与责任），用 `getFileDownloadUrl.action?fileId=` 现取现用、直链短缓存。
4. **绝不要依赖官方 OAuth 做产品主路径**：个人开发者拿不到云盘 OpenAPI 审批，别把它当可行性方案。

## 7. 关键端点与参数速查表（供开发对照）

**登录（非官方）**
- `GET  https://m.cloud.189.cn/udb/udb_login.jsp?pageId=1&pageKey=default&clientType=wap&redirectURL=...`
- `POST https://open.e.189.cn/api/logbox/oauth2/wap/appConf.do` → `lt, returnUrl, paramId, accountType`
- 从 login.html 取 `j_rsaKey` → RSA 加密账密
- `POST https://open.e.189.cn/api/logbox/oauth2/loginSubmit.do` → `{RSA}userName/{RSA}password/paramId/returnUrl/mailSuffix=@189.cn` → `toUrl` → 种 Cookie
- `GET  https://api.cloud.189.cn/open/oauth2/ssoH5.action` → 取 `accessToken`

**业务（个人云）**
- 列文件：内部 `AppFileList(folderId, 分页)`；官方 OpenAPI 形态 `POST http://api.cloud.189.cn/listFiles.action`
- 搜音乐：`POST http://api.cloud.189.cn/searchFiles.action`（`mediaType=2` 音乐，`folderId/filename/recursive/pageNum/pageSize`）
- 取直链：`GET https://api.cloud.189.cn/open/file/getFileDownloadUrl.action?fileId=<id>`，头 `accesstoken / timestamp / signature=md5(AccessToken&Timestamp&fileId)` → `res_code=0, fileDownloadUrl`
- 根目录 folderId = `-11`

**家庭云**
- 列家庭：`AppFamilyGetFamilyList()` → `familyId`
- 家庭云取直链：`AppFamilyGetFileDownloadUrl(familyId, fileId)`（用 familySessionKey 体系）
- H5 入口抓参：`https://h5.cloud.189.cn/main.html#/family`

**AList WebDAV**
- `http[s]://host:port/dav/`，Basic Auth = AList 用户/密码，需开 `Webdav Read`。

## 8. 风险与免责说明

1. **非官方 API 无 SLA、随时可能失效**：登录加密、签名、滑块风控、Cookie 有效期均由中国电信单方面调整，社区逆向实现（AList / cloudpan189-go / 脚本）需被动跟进。本报告中的端点与参数可能在你阅读时已变动，落地前请自行抓包复核。
2. **违反服务协议风险**：使用逆向接口、第三方客户端挂载个人云盘，通常违反天翼云盘用户服务协议；中国电信有权对异常账号采取限制功能、冻结登录直至封号等措施（见天翼云用户协议"异常账号处理"条款）。
   - 来源：https://www.ctyun.cn/portal/protocol/10144340
3. **账号安全责任**：应避免在 App 内明文收集用户天翼云盘账号密码；优先 Cookie 粘贴/WebDAV 自有服务器模式，把凭据留在用户自己控制的环境。
4. **本报告仅为技术可行性调研**，不构成对绕过风控、批量爬取、商用分发的鼓励；任何商业化分发需自行评估合规与法律风险，并优先争取与中国电信官方开放平台的合作授权。
